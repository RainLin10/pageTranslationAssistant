# 页面翻译助手

在 Chrome、Edge 的篡改猴（Tampermonkey）中运行的单文件脚本。支持全文预翻译、动态页面、三种大模型协议，以及浏览器本地 token 用量统计。

## 安装与使用

1. 安装并启用篡改猴。若 Chrome / Edge 提示需要“允许用户脚本”或开发者模式，请按扩展提示开启。
2. 在篡改猴中创建新脚本，用 `页面翻译助手.user.js` 的完整内容替换默认内容，然后保存。也可将该文件导入篡改猴。
3. 打开或刷新普通 HTTP/HTTPS 网页，点击右下角“译”，或使用篡改猴菜单“页面翻译助手：配置 / 用量”。
4. 填写接口类型、API Base URL、API Key、模型 ID，保存配置。默认英语 → 简体中文，可编辑术语提示词保留 `token` 等名词。
5. 点击“开启翻译”。这是**全局开关**，会同步到所有已打开的页面，并在跳转、新建标签页和重启浏览器后保留开启状态。

**首次安装全局翻译关闭。保存配置不会改变开关。** 开启后优先处理当前可见文字，后台预翻译已进入 DOM 的折叠及离屏内容，持续处理新增、展开、替换、SPA 和流式更新的文案。没有符合源语言字符特征的候选文字时不请求模型。

### 更新与面板入口

更新时在篡改猴编辑原来的“页面翻译助手”，用新版文件完整替换内容并保存，再刷新网页；现有配置、全局开关和统计沿用原存储。右下角蓝色“译”按钮用于展开面板，篡改猴菜单也提供“页面翻译助手：配置 / 用量”入口。

`1.0.1` 修复了严格 Trusted Types / CSP 页面中面板初始化失败的问题，改为 DOM 节点构建与构造样式表，并明确使用 DOM 沙箱。若刷新后连“译”按钮和脚本菜单入口都没有，请检查扩展页面是否已允许用户脚本运行；“脚本已启用”与浏览器允许脚本执行是不同设置。

“关闭翻译”取消进行中的翻译请求并停止所有页面的翻译扫描和监听，保留已经显示的译文。“恢复原文”会先关闭全局翻译，再还原当前标签页及匹配到的 iframe；其他标签页已显示的译文保留。恢复不会覆盖网页随后自行改写的文字。可用“重试失败内容”重新处理失败的片段。

“连接测试”只有点击后才请求模型，计入用量。测试使用表单当前填写的配置；页面翻译使用已经保存的配置。

### 翻译速度与长上下文模型

`1.0.2` 默认使用流式请求，一条文案的 JSON 对象完整到达后立即回填，不等整批结束；超长单个文本节点仍需等其分片全部完成，避免出现半句译文。三种协议都支持流式，兼容接口若直接返回普通 JSON 也能处理；接口明确不支持流式时，可取消“流式返回”。

- **每批片段数**：默认 300，范围 1–5,000。同批相同原文及上下文只发送一次；相同上下文通过编号共享，减少重复输入。
- **每批字符上限**：默认约 50,000，范围 2,000–1,000,000，按片段、唯一上下文和估算结构开销控制，完整请求还包含固定提示词。初次扫描会先收集更多内容再发送，避免过早产生小批次。
- **最大输出 token**：0 表示服务默认，Anthropic 必填参数在此情况下使用 8,192；正数会映射到相应协议的输出上限参数。填写所选模型实际支持的值，上下文长度与输出上限不是同一限制。
- **DeepSeek 思考模式**：对 `api.deepseek.com` 默认关闭，以减少回答前的推理等待；可勾选开启。其他服务不附加这个参数。

对于支持 1M 上下文、384K 输出的 DeepSeek 模型，可先试每批 1,000 个片段、200,000 字符、65,536 输出 token，并开启流式、关闭思考。字符数不等于 token 数；更大的批次减少请求，但不保证整页总耗时更短。可见内容优先，后台只占一个并发槽，总并发仍为每文档两个。

流中断、格式错误或输出截断时保留已完整获得的译文，只重试尚未完成的编号。最终 usage 在流结束时记账；中断且未获得最终用量的输出仍标为未知，避免把暂时的零输出或累计增量重复记入总数。

`1.0.3` 修复部分译文完成后请求占用并发槽的停顿：识别协议结束标记 / 最终用量，不再只依赖连接关闭；遇到异常译文及时结束坏流，把剩余内容拆为最多 64 个片段、约 16,000 字符的补译批次。接口持续发保活消息但 120 秒没有实际文本或思考进展时，会自动回收重试。数字编号在精确匹配请求编号时可正常处理。

面板状态会显示等待响应、模型生成、模型思考、请求重试或剩余内容补译，以及距上次回填的秒数；出现最终失败也会显示失败数量。流式回填后的队列调度合并执行，减少大页面反复扫描带来的卡顿。全局开关和已完成的译文不会因自动恢复而重置。

## 接口配置

| 类型 | 默认 Base URL | 模型名称 |
| --- | --- | --- |
| OpenAI / 兼容接口 | `https://api.openai.com/v1` | 填写服务商提供的 model ID |
| Anthropic | `https://api.anthropic.com/v1` | 填写可访问的 Claude model ID |
| Gemini | `https://generativelanguage.googleapis.com/v1beta` | 填写 Gemini model ID，不带 `models/` 前缀 |

Base URL 为包含版本路径的根地址，**不包含** `/chat/completions`、`/messages` 或模型调用路径。OpenAI 兼容中转、本地服务可填写自己的地址；免认证本地服务可不填 API Key。原生 Anthropic 使用普通 API Key；云平台 IAM 和需要额外 workspace 请求头的账号不在当前适配范围。

DeepSeek 的 OpenAI 格式可直接填写 `https://api.deepseek.com`，模型使用 `deepseek-flash` 或 `deepseek-v4-pro`；Anthropic 格式填写 `https://api.deepseek.com/anthropic` 时，脚本会使用 `/v1/messages` 端点。

脚本使用篡改猴跨域请求，支持任意用户配置的服务地址，因此声明 `@connect *`；首次请求时若出现域名权限提示，需要允许访问所配接口。请求不附带网页 cookies，不自动跟随重定向。30 秒未收到数据会超时，每次请求最多持续 30 分钟；网络错误、429、5xx 最多重试两次，模型输出 JSON 格式错误重试一次。认证失败暂停当前文档的剩余任务，修正配置或点击重试后恢复。

## token 用量

“用量”页展示今日输入、输出、总 token、请求次数，以及按日和服务商 / 模型汇总的历史。按北京时间 `Asia/Shanghai` 划分日期，每页显示 30 个有记录的日期，历史不自动过期。

- 优先使用接口实际返回的用量，统计每次 HTTP 尝试，包括连接测试、重试、格式错误和最终未写回的译文。
- OpenAI 不重复累计缓存与推理细分；Anthropic 输入包括缓存创建和读取；Gemini 输出包括推理 token。
- 缺失字段按提示词和返回文字补充估算：汉字 / 日文 / 韩文每字符一个 token，其余 Unicode 字符每四字符一个 token，向上取整。估算与接口报告分开展示，不代表具体模型 tokenizer 或账单值。
- 超时、取消或未收到响应的请求保留输入估算，输出和总量标记未知。浏览器关闭前尚未完成的请求也保留这些临时记录；无法从服务商补查真实消耗。
- 助手命中本地译文缓存时不调用模型，因此不增加用量。缓存只存在于当前文档内存，刷新后重新建立。
- 每个页面运行实例写入自己的统计分桶，汇总时合并；多个标签页和 iframe 同时翻译不会互相覆盖总数。

配置、密钥、全局开关和统计使用篡改猴本地存储，按浏览器配置文件隔离。统计只保存日期、服务商、模型和计数，不保存网页文字、提示词正文、密钥或完整响应；不上传统计数据。删除脚本、清理扩展数据或更换浏览器配置文件可能导致本地数据丢失。

## 翻译范围

保留原 DOM 元素和事件，仅更新文本节点以及 `title`、`placeholder`、`aria-label`、`alt`。跳过代码、脚本、样式、可编辑区域、表单值、选择框、`translate="no"` 和 `.notranslate` 内容。支持可访问的 open Shadow DOM 与符合匹配规则、允许用户脚本运行的 iframe。

本地字符过滤只用于判断是否有候选文案，不能可靠区分使用相同文字系统的语言；例如英语、法语、西班牙语短文案仍由模型确认源语言。网页文字和原文上下文会发送给所配模型。术语保留依赖提示词与模型输出。

浏览器内部页面、图片文字、Canvas、closed Shadow DOM 以及禁止脚本运行的 iframe 无法处理。普通 DOM 变化采用 150ms 合并、300ms 最大等待；延迟创建的 Shadow DOM 每两秒补查。最终显示时间还取决于扫描、队列、网络和模型响应。

## 开发与验证

需要 Node.js 20+：

```powershell
npm install
npm run check
npm test
```

默认使用已安装的 Edge 执行 Playwright 浏览器测试。若需要验证 Chrome，可安装 Chrome，并把 `playwright.config.cjs` 的 `channel` 改为 `chrome`，或增加对应 project。单独运行 `npm run test:unit` / `npm run test:browser`。

测试直接运行交付脚本，模拟 GM API 与模型服务，覆盖协议、记账、动态 DOM、过期结果、全局开关、并发、跨域 iframe 和页面刷新。测试不会访问真实模型或消耗真实 API token。真实篡改猴授权行为和真实模型翻译质量需要用实际安装及配置验证。
